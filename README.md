# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer web application that helps users evaluate resumes with ATS-style analysis, smart feedback, keyword insights, and resume scoring.

Built using React, Python, and modern web technologies.

---

## 🚀 Features

- 📄 Resume Upload & Analysis
- 🤖 AI-based Resume Evaluation
- 📊 ATS Score Generation
- 🧠 Smart Resume Feedback
- 🔍 Keyword & Skill Detection
- 📈 Resume Insights Dashboard
- ⚡ Fast & Responsive UI
- 📱 Mobile Friendly Design
- 🌙 Modern Clean Interface

---

## 🛠️ Tech Stack

### Frontend
- React.js

- CSS

### Backend

- Flask / FastAPI *(update according to your backend)*

- AI/NLP-based Resume Analysis
